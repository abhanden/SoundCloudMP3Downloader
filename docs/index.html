Paste a link. Get the MP3 with its cover inside.

A desktop app that saves SoundCloud tracks, playlists and albums as 320 kbps MP3 and writes artist, title and cover art into the file. Check the cover below before you install anything.

A real MP3 with complete tags

Earlier versions of this kind of tool left M4A files behind and skipped covers. This one converts every track with FFmpeg, then checks the result by reading the tags back from disk.

  1. yt-dlpFetches the best audio stream and the track metadata.
  2. FFmpegConverts to MP3 at 320 kbps.
  3. PillowLoads the 500 × 500 cover and converts it to a real JPEG.
  4. mutagenWrites the ID3v2.3 tags and reads them back to verify.
FieldID3 frameContent
TitleTIT2Track title from SoundCloud
ArtistTPE1Artist, or the uploader name if none is set
AlbumTALBPlaylist or album title, when you download one
CoverAPICFront cover, image/jpeg, t500x500 version of the artwork

ID3v2.3 and JPEG are deliberate: Windows Explorer and Mp3tag show those covers reliably, WebP covers and ID3v2.4 tags often stay blank.

Install

You need Python 3.9 or newer and FFmpeg. Pick your system.
